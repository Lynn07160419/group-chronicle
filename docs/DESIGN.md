# 设计记录

## 数据依据

原始资料为 `references/【在更新！请更新！】团名查重库（小团编年史）.xlsx`。工作表包含小团、学期、时间三列，导入 273 条记录、243 个不同原始团名条目。斜杠分隔的多个别名仍以原始整条名称展示，查重时逐个比较。

## 页面结构

- 顶部保留手语分社标识、编年史标题及统计数量。
- 左侧为关键词搜索、学期和星期筛选、历史表格及分页。
- 右侧为新小团录入、即时查重与保存反馈。
- 蓝色用于主要按钮和品牌标识，标题采用深色，辅助文字采用灰色。
- 小屏幕改为单列布局。

## 已采纳的调整

1. 删除顶部重复出现的“小团档案”“本地编年史”、年份提示和宣传语。
2. 删除标题蓝色装饰句号，缩减顶部留白。
3. 删除页脚“新增记录保存在本机 · 原始 Excel 保持不变”的提示。
4. 直接打开 HTML 文件时跳转到本地服务入口。
5. 增加“导出全部 Excel”，导出所有已保存记录，不随当前筛选变化。
